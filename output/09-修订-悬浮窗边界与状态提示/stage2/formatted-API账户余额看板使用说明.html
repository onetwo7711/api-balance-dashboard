API账户余额看板使用说明

一、软件用途

API账户余额看板是一款在本机运行的桌面应用，用于同时查询并集中展示智谱GLM与DeepSeek两个平台的API账户剩余金额。

  • 软件是一个自带后台服务的本地应用：双击启动后即可使用，不需要安装运行时、不需要手动打开浏览器，也不需要执行任何命令。
  • 每个平台对应一张余额卡片，显示剩余金额、币种、最近更新时间，以及接口返回的余额构成明细、数据来源和本次查询耗时。
  • 支持手动刷新与定时自动刷新，并给出距下次刷新的倒计时。
  • 密钥无效、网络异常、接口变更等情况会在对应卡片中给出明确的错误名称、错误码和处置建议。
  • 提供主窗口与悬浮窗两种运行方式，悬浮窗可常驻桌面随时查看。

功能边界：软件只做余额的读取与展示，不提供账号登录、充值、账单明细与历史趋势、余额告警或通知、数据导出、多账户切换，也不修改平台账户设置。查询过程不调用模型推理，不产生token消耗。

二、适用对象与运行环境

  • 适用对象：已持有智谱GLM或DeepSeek平台API密钥（平台也称API Key），需要在同一界面查看账户余额的个人用户。无需开发经验。可以只配置其中一个平台，另一张卡片会显示「尚未配置API密钥」提示，不影响已配置平台的使用。
  • 操作系统：macOS（Apple芯片）。应用自带运行环境，安装后双击即可运行，无需安装任何依赖。
  • 网络条件：本机能够访问api.deepseek.com与open.bigmodel.cn；若使用代理，请先确保网络请求可以到达上述地址。
  • 访问范围：应用只在本机回环地址上提供查询服务，同一网络中的其他设备无法访问，密钥不会被暴露到局域网。
  • 开发调试：仅在需要修改软件时，才需要另行准备Node.js 18及以上版本。

三、运行前准备

  1. 安装应用：把API账户余额看板.app拖入「应用程序」文件夹，或直接在解压后的目录中使用。
  2. 准备两个平台的API密钥。

- DeepSeek：在平台控制台的API Keys页面创建API密钥。 - 智谱GLM：在标准API Key页面创建标准API密钥（按量付费或资源包类型）。Coding Plan套餐密钥不用于查询账户余额，用错类型可能查到0或不匹配的金额。 - 密钥必须与所填接口地址的站点一致，国内站与国际站的密钥互不通用。

  1. 首次打开时，macOS可能提示「无法验证开发者」，这是因为安装包未做代码签名。在访达中右键点击应用并选择「打开」，或在命令行执行xattr -dr com.apple.quarantine "/Applications/API账户余额看板.app"。
  2. 妥善保管API密钥。软件不会把密钥显示回界面，也不会上传到任何服务器。

四、启动与退出

启动

  • 双击应用图标启动。应用自动开启后台查询服务并弹出主窗口，无需手动打开浏览器或运行任何命令。
  • 主窗口右上角有「悬浮窗」按钮，点击后打开悬浮窗并关闭主窗口，应用转为只保留悬浮窗的常驻模式；需要完整界面时按CommandOrControl+Shift+W或点悬浮窗上的「主窗口」按钮即可唤回。
  • 服务默认使用8787端口；若该端口被占用，应用会自动顺延到8788至8806之间的可用端口，界面与功能不受影响。
  • 若8787至8806全部被占用，应用会弹出错误提示并退出，关闭占用端口的程序后重新启动即可。
  • 应用为单实例运行：再次双击应用图标不会启动第二个服务，只会唤起已在运行的主窗口。

退出

  • 按CommandOrControl+Q退出，或在菜单栏选择「窗口→退出」。
  • 退出不会清除已保存的配置，下次启动会自动读取；应用也不会把密钥保存在界面缓存里。

悬浮窗形态

应用还提供常驻桌面的悬浮窗，用于把余额固定在可见位置随时查看。

  • 悬浮窗为无边框半透明小窗，顶部有标题条，可按住拖动到任意位置。
  • 标题条上依次是「刷新」「透明度」「置顶」「主窗口」和关闭按钮：透明度滑块可在30%至100%之间调节；「置顶」按钮切换是否始终显示在其他窗口之上。
  • 窗口尺寸与位置、透明度、置顶状态都会被记住，下次启动自动恢复。
  • 快捷键：CommandOrControl+Shift+B显示或隐藏悬浮窗，CommandOrControl+Shift+W唤起主窗口。macOS首次使用全局快捷键时，如系统未授权，会在主窗口页脚提示，需在系统设置→隐私与安全性→辅助功能中允许本应用。
  • 悬浮窗与主窗口展示同一份数据，在任一窗口修改的设置会同步生效。
  • 悬浮窗只保留余额、币种与最近更新时间，接口来源与本次耗时等明细不显示，界面更紧凑，也没有底部投影。
  • 悬浮窗四周有一圈可见描边，明确标示出可操作范围：静止时为细灰描边；拖动窗口时变为加粗深色描边并在顶部显示状态条；调整大小时变为琥珀色描边，并在四角出现缩放标记。三种状态的提示元素都不接收鼠标事件，不会遮挡内部按钮，也不影响拖拽与缩放手势。
  • 悬浮窗里每张卡片右上角同样有单独的刷新按钮，可只刷新某一个平台。

六、设置项说明

点击「设置」展开设置面板，填写后点击「保存并刷新」生效；点击「取消」或右上角关闭符号则不保存本次改动。

补充说明：

  • 密钥输入框始终以空白显示。若该平台已配置，占位文字会显示「已配置（尾号xxxx），留空表示不修改」，界面不会显示完整密钥。
  • API密钥支持直接粘贴：主窗口按CommandOrControl+V即可，菜单栏「编辑」菜单也提供粘贴、复制、剪切与全选。
  • 地址类设置必须是完整的http或https地址；自动刷新间隔只接受0（关闭）或30至86400秒之间的整数。不符合要求时保存会失败并给出弹出提示。
  • 两个平台的密钥保存在本机的用户配置目录中，文件名为config.json，权限仅当前用户可读，macOS路径为~/Library/Application Support/API账户余额看板/config.json。

七、典型使用场景

首次配置并查看余额

  1. 双击应用图标启动，等待主窗口打开。
  2. 此时两张卡片显示「尚未配置API密钥」及对应建议。
  3. 点击「设置」，分别填入智谱GLM与DeepSeek的API密钥；按账户实际情况选择智谱余额币种和自动刷新间隔。
  4. 点击「保存并刷新」。界面收起设置面板并重新查询，卡片显示金额、币种与最近更新时间。

日常查看与手动刷新

  • 每次启动应用会自动查询一次。点击「刷新余额」可立即重新查询。
  • 每张卡片右上角的圆形刷新按钮可只刷新该平台，另一个平台的卡片与整体状态不受影响；刷新中该按钮转为转圈并暂时禁用。
  • 查询进行中按钮显示「查询中…」并暂时禁用，避免重复发起请求。
  • 查询成功后，状态条显示「两个平台均查询成功」并附上本次时间；若有平台失败，状态条显示失败数量。

定时自动刷新

  • 在「自动刷新间隔」中选择一个间隔，状态条显示「自动刷新：每X分钟」以及「距下次刷新mm:ss」倒计时。
  • 每次查询完成后重新计时；切回主窗口或悬浮窗时，若已到刷新时点会自动补刷一次。
  • 选择「关闭」后只保留手动刷新，倒计时区不再显示内容。

更换或清除密钥

  • 更换：在对应密钥输入框填入新值并保存，旧值即被覆盖。
  • 清除：点击对应分组的「清除」按钮，该平台的密钥立即被删除，卡片随即给出「尚未配置API密钥」提示。
  • 若密钥疑似泄露，建议先在平台控制台删除该密钥、创建新密钥，再回到设置中填写新值。

平台接口变更时

  • 智谱官方未提供公开的余额查询API，软件内置三个平台控制台所使用的账户接口并依次自动回退。若均不可用，可在「高级选项 → 自定义余额接口地址」填写能返回余额字段的完整地址，保存后继续查询。
  • DeepSeek侧可在「余额接口地址」中改填可用的兼容地址。
  • 接口恢复后，把自定义地址清空并保存，即可回到内置接口。

八、输入与输出说明

输入

软件只接收以下输入，不需要账号密码、账户ID，也不接收文件：

  • 设置面板中的两个API密钥、币种选择、接口地址、自定义余额接口地址、自动刷新间隔。
  • 界面上的操作：刷新余额、单平台刷新、展开或收起设置、保存并刷新、取消、清除密钥。

密钥由后台服务读取后用于向平台发起带鉴权头的只读请求，单次请求默认等待12秒。

输出

每张余额卡片包含以下内容：

输出项说明
平台名称与状态智谱GLM或DeepSeek，以及正常、余额不足、查询失败等状态
金额按币种显示¥或$，保留两位小数；将鼠标悬停在金额上可查看接口返回的精确值
币种徽标CNY或USD；尚未查询时显示「待查询」
说明文字例如「数据来自平台实时接口。」；余额不足时提示API调用可能被拒绝
最近更新时间本地日期时间，并附「刚刚」「N分钟前」「N小时前」「N天前」
接口来源查询成功时显示本次实际使用的接口名称；悬浮窗形态不显示
本次耗时查询成功时显示本次请求耗时；悬浮窗形态不显示
余额明细平台返回才显示。智谱可能为充值余额、赠金余额、代金券余额、累计消费、资源包；DeepSeek为赠金余额、充值余额，存在多币种时带币种前缀并列出各币种总余额
错误提示框查询失败时显示错误名称、错误码、处置建议，以及接口返回的详细信息

其他输出：

  • 状态条汇总显示两个平台的查询成败，并显示自动刷新状态与倒计时。
  • 界面底部弹出提示显示设置保存、密钥清除、保存失败以及无法连接本地服务等操作结果。
  • 查询成功后，结果会保存在应用本地缓存中，下次打开可立即看到；查询失败且存在历史成功数据时，卡片仍显示上次的金额，同时给出本次失败的错误提示。清除应用缓存会清空这部分缓存，但不会影响保存在本机的密钥。

币种说明：智谱的币种由设置项决定；DeepSeek的币种由接口返回的CNY或USD自动识别。若DeepSeek账户存在多个币种，主金额显示第一种币种，其余币种在余额明细中列出。

十、注意事项与功能边界

  • 密钥只保存在本机的用户配置目录config.json，界面只接收脱敏后的尾号信息，不上传任何凭据。
  • 智谱官方未提供公开的余额查询API，软件使用平台控制台所使用的账户接口并做多端点回退；该接口可能随平台改版失效，届时可填写自定义余额接口地址，或直接到平台控制台查看。DeepSeek使用官方余额接口。
  • 智谱标准API密钥与Coding Plan套餐密钥分开管理，用错类型可能查到0或不匹配的金额；密钥也必须与接口站点匹配。
  • 金额按两位小数展示，精确值需查看金额悬停提示。余额明细随平台实际返回内容变化，平台未返回的字段不会显示。
  • 自动刷新会按设定间隔持续向平台发起只读请求。间隔过短可能触发平台限流，建议使用界面提供的最小间隔或更大的间隔。
  • 软件不提供账号密码登录、充值、账单明细与历史趋势、余额告警与通知、数据导出、多账户切换，也不修改平台账户设置。
  • 早期版本把配置保存在程序目录下的data/config.json；升级后程序改用系统用户配置目录，首次启动会把旧目录中的配置自动复制过去，旧文件保留不删除，确认无误后可自行清理。
  • 需要把配置放到自定义位置时，可在启动前设置环境变量BALANCE_DATA_DIR指定目录，程序改用该目录存放config.json。
  • 配置文件与窗口状态文件window-state.json同在系统用户数据目录中并存，互不覆盖。
  • 悬浮窗透明度调节依赖系统窗口合成能力，个别系统下不可用，此时滑块会被禁用。
  • 安装包未做代码签名与公证，首次打开需手动确认；仅在可信来源获取安装包时再执行。
