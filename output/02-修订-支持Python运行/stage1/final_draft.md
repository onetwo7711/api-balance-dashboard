# API账户余额看板使用说明

## 一、软件用途

API账户余额看板是一款在本机运行的余额查看工具，用于同时查询并集中展示智谱GLM与DeepSeek两个平台的API账户剩余金额。

- 软件由本地服务与浏览器页面组成。本地服务提供Python与Node.js两套功能等价的后端，按运行环境自动选择；它负责保存配置、向两个平台发起只读查询，浏览器页面负责展示结果。两套后端共用同一份配置和同一个页面。
- 每个平台对应一张余额卡片，显示剩余金额、币种、最近更新时间，以及接口返回的余额构成明细、数据来源和本次查询耗时。
- 支持手动刷新与定时自动刷新，并给出距下次刷新的倒计时。
- 密钥无效、网络异常、接口变更等情况会在对应卡片中给出明确的错误名称、错误码和处置建议。
- 页面采用响应式布局，桌面浏览器并排显示两张卡片，手机和平板自动改为单列。

功能边界：软件只做余额的读取与展示，不提供账号登录、充值、账单明细与历史趋势、余额告警或通知、数据导出、多账户切换，也不修改平台账户设置。查询过程不调用模型推理，不产生token消耗。

## 二、适用对象与运行环境

- 适用对象：已持有智谱GLM或DeepSeek平台API密钥（平台也称API Key），需要在同一页面查看账户余额的个人用户。无需开发经验。可以只配置其中一个平台，另一张卡片会显示「尚未配置API密钥」提示，不影响已配置平台的使用。
- 操作系统：macOS、Windows、Linux均可，只要能运行Python 3或Node.js。软件自身不安装任何第三方依赖包。
- 软件环境：Python 3（macOS通常自带，无需下载）或Node.js 18及以上版本，二选一即可；现代桌面或移动端浏览器。
- 网络条件：本机能够访问`api.deepseek.com`与`open.bigmodel.cn`；若使用代理，请先确保终端中的网络请求可以到达上述地址。
- 默认访问范围：服务默认只监听本机地址`127.0.0.1`，其他设备无法访问。

## 三、运行前准备

1. 确认本机具备任一可用运行时，无需下载或安装任何依赖。macOS通常自带系统Python，可在终端执行`/usr/bin/python3 -V`确认；若使用Node.js，可执行`node -v`确认版本不低于18。启动脚本会自动选择可用运行时。
2. 准备两个平台的API密钥。
   - DeepSeek：在平台控制台的API Keys页面创建API密钥。
   - 智谱GLM：在标准API Key页面创建标准API密钥（按量付费或资源包类型）。Coding Plan套餐密钥不用于查询账户余额，用错类型可能查到0或不匹配的金额。
   - 密钥必须与所填接口地址的站点一致，国内站与国际站的密钥互不通用。
3. 确认软件目录包含`server.py`、`server.js`、`public`目录（含`index.html`、`styles.css`、`app.js`）以及`start.command`。`data`目录会在首次保存配置时自动创建，无需手工建立。
4. 妥善保管API密钥。软件不会把密钥显示回页面，也不会上传到任何服务器。

## 四、启动与退出

### 启动

- macOS：双击软件目录中的`start.command`。脚本自动优先使用系统自带的Python 3，其次使用PATH中的python3，最后才尝试Node.js；终端会显示所选运行时和「API账户余额看板已启动」及访问地址，随后自动打开浏览器。若三者都不可用，终端会给出提示并等待回车后关闭。
- macOS、Windows、Linux通用方式：在终端进入软件目录，执行`python3 server.py`或`node server.js`，再在浏览器手动打开`http://127.0.0.1:8787`。两种命令启动的服务功能完全一致。
- 可选环境变量（在macOS或Linux终端中使用）：
  - `PORT`：服务端口，默认8787。示例：`PORT=8788 python3 server.py`。
  - `HOST`：监听地址，默认`127.0.0.1`；设为`0.0.0.0`可供同一局域网内的设备访问。示例：`HOST=0.0.0.0 python3 server.py`。
  - `NO_OPEN=1`：启动时不自动打开浏览器。示例：`NO_OPEN=1 python3 server.py`。
- 端口被占用时，终端会提示「端口8787已被占用」并建议使用`PORT`指定其他端口；换端口后需按新端口打开页面。
- 以`HOST=0.0.0.0`启动时，终端会列出可用的局域网地址，页面底部也会给出手机访问地址提示。

### 退出

- 在运行本地服务的终端按Ctrl+C，或直接关闭该终端窗口，服务即停止。
- 通过`start.command`启动时，服务停止后终端会显示「按回车键关闭窗口…」，按回车即可关闭。
- 退出服务不会清除已保存的配置，下次启动会自动读取。浏览器页面本身不保存密钥。

## 五、界面与功能入口

| 区域 | 位置 | 作用 |
|------|------|------|
| 刷新余额按钮 | 页面顶部右侧 | 立即向两个平台重新查询一次余额 |
| 设置按钮 | 页面顶部右侧 | 展开或收起设置面板 |
| 状态条 | 顶部操作区下方 | 显示整体查询结果、自动刷新状态、距下次刷新的倒计时 |
| 余额卡片 | 页面主体 | 智谱GLM与DeepSeek各一张，展示金额与查询详情 |
| 设置面板 | 点击设置按钮后展开 | 配置密钥、接口地址、币种与自动刷新间隔 |
| 页面底部 | 最下方 | 说明密钥保存位置；存在局域网地址时给出手机访问提示 |
| 弹出提示 | 页面底部中间 | 短暂显示保存成功、清除成功、保存失败、无法连接本地服务等结果 |

卡片状态共有五种：正常、余额不足、查询失败、等待查询、查询中。状态通过卡片标题旁的小圆点和右上角文字表示。

## 六、设置项说明

点击「设置」展开设置面板，填写后点击「保存并刷新」生效；点击「取消」或右上角关闭符号则不保存本次改动。

| 设置项 | 所属分组 | 作用 | 默认值 |
|--------|----------|------|--------|
| API密钥 | 智谱GLM | 填写新密钥即覆盖旧值；输入框留空表示不修改 | 无 |
| 余额币种 | 智谱GLM | 选择CNY·人民币或USD·美元。智谱接口不返回币种，需在此指定 | CNY |
| 接口基础地址 | 智谱GLM·高级选项 | 内置账户接口的地址前缀 | `https://open.bigmodel.cn` |
| 自定义余额接口地址 | 智谱GLM·高级选项 | 留空时依次尝试内置接口；填写后只使用该地址 | 留空 |
| API密钥 | DeepSeek | 填写新密钥即覆盖旧值；输入框留空表示不修改 | 无 |
| 余额接口地址 | DeepSeek | 官方余额接口地址，可改为可用的兼容地址 | `https://api.deepseek.com/user/balance` |
| 自动刷新间隔 | 公共 | 关闭、每1分钟、每5分钟、每15分钟、每30分钟 | 每5分钟 |
| 清除按钮 | 两个分组各一个 | 立即删除该平台已保存的密钥，其他设置不受影响 | 无 |
| 保存并刷新 | 公共 | 保存全部设置并立即重新查询 | 无 |

补充说明：

- 密钥输入框始终以空白显示。若该平台已配置，占位文字会显示「已配置（尾号xxxx），留空表示不修改」，页面不会显示完整密钥。
- 地址类设置必须是完整的http或https地址；自动刷新间隔只接受0（关闭）或30至86400秒之间的整数。不符合要求时保存会失败并给出弹出提示。
- 两个平台的密钥分别保存在本机`data/config.json`中，该文件权限仅当前用户可读。

## 七、典型使用场景

### 首次配置并查看余额

1. 按「启动与退出」一节启动软件，浏览器打开页面。
2. 此时两张卡片显示「尚未配置API密钥」及对应建议。
3. 点击「设置」，分别填入智谱GLM与DeepSeek的API密钥；按账户实际情况选择智谱余额币种和自动刷新间隔。
4. 点击「保存并刷新」。页面收起设置面板并重新查询，卡片显示金额、币种与最近更新时间。

### 日常查看与手动刷新

- 每次打开页面会自动查询一次。点击「刷新余额」可立即重新查询。
- 查询进行中按钮显示「查询中…」并暂时禁用，避免重复发起请求。
- 查询成功后，状态条显示「两个平台均查询成功」并附上本次时间；若有平台失败，状态条显示失败数量。

### 定时自动刷新

- 在「自动刷新间隔」中选择一个间隔，状态条显示「自动刷新：每X分钟」以及「距下次刷新mm:ss」倒计时。
- 每次查询完成后重新计时；从其他标签页或后台切回本页面时，若已到刷新时点会自动补刷一次。
- 选择「关闭」后只保留手动刷新，倒计时区不再显示内容。

### 更换或清除密钥

- 更换：在对应密钥输入框填入新值并保存，旧值即被覆盖。
- 清除：点击对应分组的「清除」按钮，该平台的密钥立即被删除，卡片随即给出「尚未配置API密钥」提示。
- 若密钥疑似泄露，建议先在平台控制台删除该密钥、创建新密钥，再回到设置中填写新值。

### 在手机或平板上查看

1. 以`HOST=0.0.0.0 python3 server.py`启动服务（使用Node.js后端时改为`HOST=0.0.0.0 node server.js`）。
2. 在同一局域网内的手机或平板浏览器中，打开终端或页面底部给出的局域网地址。
3. 页面自动切换为单列布局，按钮铺满宽度，卡片中的时间与明细自动折行。

### 平台接口变更时

- 智谱官方未提供公开的余额查询API，软件内置三个平台控制台所使用的账户接口并依次自动回退。若均不可用，可在「高级选项 → 自定义余额接口地址」填写能返回余额字段的完整地址，保存后继续查询。
- DeepSeek侧可在「余额接口地址」中改填可用的兼容地址。
- 接口恢复后，把自定义地址清空并保存，即可回到内置接口。

## 八、输入与输出说明

### 输入

软件只接收以下输入，不需要账号密码、账户ID，也不接收文件：

- 设置面板中的两个API密钥、币种选择、接口地址、自定义余额接口地址、自动刷新间隔。
- 页面上的操作：刷新余额、展开或收起设置、保存并刷新、取消、清除密钥。

密钥由本地服务读取后用于向平台发起带鉴权头的只读请求，单次请求默认等待12秒。

### 输出

每张余额卡片包含以下内容：

| 输出项 | 说明 |
|--------|------|
| 平台名称与状态 | 智谱GLM或DeepSeek，以及正常、余额不足、查询失败等状态 |
| 金额 | 按币种显示¥或$，保留两位小数；桌面端将鼠标悬停在金额上可查看接口返回的精确值 |
| 币种徽标 | CNY或USD；尚未查询时显示「待查询」 |
| 说明文字 | 例如「数据来自平台实时接口。」；余额不足时提示API调用可能被拒绝 |
| 最近更新时间 | 本地日期时间，并附「刚刚」「N分钟前」「N小时前」「N天前」 |
| 接口来源 | 查询成功时显示本次实际使用的接口名称 |
| 本次耗时 | 查询成功时显示本次请求耗时 |
| 余额明细 | 平台返回才显示。智谱可能为充值余额、赠金余额、代金券余额、累计消费、资源包；DeepSeek为赠金余额、充值余额，存在多币种时带币种前缀并列出各币种总余额 |
| 错误提示框 | 查询失败时显示错误名称、错误码、处置建议，以及接口返回的详细信息 |

其他输出：

- 状态条汇总显示两个平台的查询成败，并显示自动刷新状态与倒计时。
- 页面底部弹出提示显示设置保存、密钥清除、保存失败以及无法连接本地服务等操作结果。
- 查询成功后，结果会保存在当前浏览器的本地存储中，下次打开页面可立即看到；查询失败且存在历史成功数据时，卡片仍显示上次的金额，同时给出本次失败的错误提示。清除浏览器站点数据会清空这部分缓存，但不会影响保存在本机的密钥。

币种说明：智谱的币种由设置项决定；DeepSeek的币种由接口返回的CNY或USD自动识别。若DeepSeek账户存在多个币种，主金额显示第一种币种，其余币种在余额明细中列出。

## 九、常见异常提示与处理

| 界面提示 | 错误码 | 含义与建议操作 |
|----------|--------|----------------|
| 尚未配置API密钥 | NOT_CONFIGURED | 该平台还未填写密钥。在设置中填入对应平台的API密钥后刷新 |
| API密钥无效或已过期 | INVALID_KEY | 检查密钥是否填写完整、是否已在平台删除，以及密钥所属站点与接口地址是否匹配 |
| 账户余额不足 | INSUFFICIENT | 平台拒绝继续提供服务。到平台充值后再试 |
| 请求过于频繁 | RATE_LIMITED | 平台已限流。稍后重试，或在设置中增大自动刷新间隔 |
| 平台服务暂时不可用 | SERVER_ERROR | 平台接口返回服务端错误。稍后由自动刷新或手动刷新重试 |
| 接口地址不存在或已变更 | ENDPOINT | 检查接口地址，或在设置中填写自定义余额接口地址 |
| 请求超时 | TIMEOUT | 检查网络与代理设置，稍后手动刷新 |
| 网络连接失败 | NETWORK | 检查网络、代理或防火墙能否访问平台接口 |
| 接口响应格式无法识别 | PARSE | 平台接口可能已变更。可填写自定义余额接口地址 |
| 接口未返回余额数据 | NO_BALANCE | 该密钥类型可能不支持余额查询。确认密钥权限，或到平台控制台查看 |
| 查询失败 | UNKNOWN | 查看错误提示框中的接口返回详情，稍后重试 |
| 配置保存失败 | CONFIG | 检查接口地址是否为完整的http或https地址，或刷新间隔是否合法 |
| 无法连接本地服务 | 页面提示 | 确认本地服务仍在运行，然后重新打开页面 |
| 端口8787已被占用 | 终端提示 | 改用其他端口，例如`PORT=8788 python3 server.py` |
| 未检测到可用的Python 3或Node.js 18及以上版本 | 终端提示 | 优先使用系统自带的`/usr/bin/python3`；若确实没有运行时，安装Python 3或Node.js 18及以上版本之一 |

查询失败时，卡片内的错误提示框会同时给出错误码、处置建议和接口返回详情；状态条会汇总显示失败的平台数量。

## 十、注意事项与功能边界

- 密钥只保存在本机`data/config.json`，页面只接收脱敏后的尾号信息，不上传任何凭据。以`HOST=0.0.0.0`开放局域网访问时，同一网络内的其他设备可以打开页面并触发余额查询，请只在可信网络使用该方式。
- 智谱官方未提供公开的余额查询API，软件使用平台控制台所使用的账户接口并做多端点回退；该接口可能随平台改版失效，届时可填写自定义余额接口地址，或直接到平台控制台查看。DeepSeek使用官方余额接口。
- 智谱标准API密钥与Coding Plan套餐密钥分开管理，用错类型可能查到0或不匹配的金额；密钥也必须与接口站点匹配。
- 金额按两位小数展示，精确值需查看金额悬停提示。余额明细随平台实际返回内容变化，平台未返回的字段不会显示。
- 自动刷新会按设定间隔持续向平台发起只读请求。间隔过短可能触发平台限流，建议使用界面提供的最小间隔或更大的间隔。
- 软件不提供账号密码登录、充值、账单明细与历史趋势、余额告警与通知、数据导出、多账户切换，也不修改平台账户设置。
- Python版与Node.js版后端功能等价，共用`data/config.json`与同一套页面；切换启动方式不会丢失已保存的配置。
- 关闭本地服务后页面将无法刷新；已保存的配置与浏览器中的历史余额快照仍会保留，下次启动后可继续使用。
