API账户余额看板使用说明

一、软件用途

API账户余额看板是一款在本机运行的余额查看工具，用于同时查询并集中展示智谱GLM与DeepSeek两个平台的API账户剩余金额。

  • 软件由本地服务与浏览器页面组成。本地服务提供Python与Node.js两套功能等价的后端，按运行环境自动选择；它负责保存配置、向两个平台发起只读查询，浏览器页面负责展示结果。两套后端共用同一份配置和同一个页面。
  • 每个平台对应一张余额卡片，显示剩余金额、币种、最近更新时间，以及接口返回的余额构成明细、数据来源和本次查询耗时。
  • 支持手动刷新与定时自动刷新，并给出距下次刷新的倒计时。
  • 密钥无效、网络异常、接口变更等情况会在对应卡片中给出明确的错误名称、错误码和处置建议。
  • 页面采用响应式布局，桌面浏览器并排显示两张卡片，手机和平板自动改为单列。

功能边界：软件只做余额的读取与展示，不提供账号登录、充值、账单明细与历史趋势、余额告警或通知、数据导出、多账户切换，也不修改平台账户设置。查询过程不调用模型推理，不产生token消耗。

二、适用对象与运行环境

  • 适用对象：已持有智谱GLM或DeepSeek平台API密钥（平台也称API Key），需要在同一页面查看账户余额的个人用户。无需开发经验。可以只配置其中一个平台，另一张卡片会显示「尚未配置API密钥」提示，不影响已配置平台的使用。
  • 操作系统：macOS、Windows、Linux均可，只要能运行Python 3或Node.js。软件自身不安装任何第三方依赖包。
  • 软件环境：Python 3（macOS通常自带，无需下载）或Node.js 18及以上版本，二选一即可；现代桌面或移动端浏览器。
  • 网络条件：本机能够访问api.deepseek.com与open.bigmodel.cn；若使用代理，请先确保终端中的网络请求可以到达上述地址。
  • 默认访问范围：服务默认只监听本机地址127.0.0.1，其他设备无法访问。
  • 桌面应用形态：提供独立窗口与悬浮窗两种运行方式，当前提供macOS版本（Apple芯片）。

三、运行前准备

  1. 确认本机具备任一可用运行时，无需下载或安装任何依赖。macOS通常自带系统Python，可在终端执行/usr/bin/python3 -V确认；若使用Node.js，可执行node -v确认版本不低于18。启动脚本会自动选择可用运行时。
  2. 准备两个平台的API密钥。

- DeepSeek：在平台控制台的API Keys页面创建API密钥。 - 智谱GLM：在标准API Key页面创建标准API密钥（按量付费或资源包类型）。Coding Plan套餐密钥不用于查询账户余额，用错类型可能查到0或不匹配的金额。 - 密钥必须与所填接口地址的站点一致，国内站与国际站的密钥互不通用。

  1. 确认软件目录包含server.py、server.js、public目录（含index.html、styles.css、app.js）以及start.command。data目录会在首次保存配置时自动创建，无需手工建立。
  2. 妥善保管API密钥。软件不会把密钥显示回页面，也不会上传到任何服务器。

四、启动与退出

启动

  • macOS：双击软件目录中的start.command。脚本自动优先使用系统自带的Python 3，其次使用PATH中的python3，最后才尝试Node.js；终端会显示所选运行时和「API账户余额看板已启动」及访问地址，随后自动打开浏览器。若三者都不可用，终端会给出提示并等待回车后关闭。
  • macOS、Windows、Linux通用方式：在终端进入软件目录，执行python3 server.py或node server.js，再在浏览器手动打开http://127.0.0.1:8787。两种命令启动的服务功能完全一致。
  • 可选环境变量（在macOS或Linux终端中使用）：

- PORT：服务端口，默认8787。示例：PORT=8788 python3 server.py。 - HOST：监听地址，默认127.0.0.1；设为0.0.0.0可供同一局域网内的设备访问。示例：HOST=0.0.0.0 python3 server.py。 - NO_OPEN=1：启动时不自动打开浏览器。示例：NO_OPEN=1 python3 server.py。

  • 端口被占用时脚本会自行处理。若占用者就是本软件自身，终端提示「检测到余额看板已在运行」并直接打开已有页面；若被其他程序占用，自动切换到下一个可用端口（例如8788）并在终端显示新端口，浏览器随后打开新地址。需要固定端口时也可手动指定，例如PORT=8788。
  • 以HOST=0.0.0.0启动时，终端会列出可用的局域网地址，页面底部也会给出手机访问地址提示。

退出

  • 在运行本地服务的终端按Ctrl+C，或直接关闭该终端窗口，服务即停止。
  • 通过start.command启动时，服务停止后终端会显示「按回车键关闭窗口…」，按回车即可关闭。
  • 退出服务不会清除已保存的配置，下次启动会自动读取。浏览器页面本身不保存密钥。

桌面应用形态

除浏览器访问外，软件同时提供桌面应用形态，把看板装进本机窗口，不再依赖手动打开浏览器。

  • 主窗口形态：标准应用窗口，顶部为标题区与「刷新余额」「设置」按钮，下方是状态条与两张余额卡片，布局与浏览器形态完全一致；窗口可自由缩放与移动，尺寸和位置会被记住，下次启动自动恢复。
  • 桌面应用自带本地服务，启动应用即可使用，不需要另外运行命令行版本；浏览器形态、命令行形态与桌面应用形态共用同一份配置，在任一处保存的密钥在其他形态中同样生效。
  • 安装包：macOS为.dmg（Apple芯片版）与zip压缩包，应用目录也可直接使用。macOS版本未做代码签名，首次打开需在访达中右键点击应用并选择「打开」，或在命令行执行xattr -dr com.apple.quarantine "/Applications/API账户余额看板.app"。
  • 开发调试：在desktop目录执行npm start启动应用，npm run pack生成免安装目录，npm run dist按当前平台打包；菜单「开发者工具」可打开调试面板。

悬浮窗形态

桌面应用还提供常驻桌面的悬浮窗，用于把余额固定在可见位置随时查看。

  • 悬浮窗为无边框半透明小窗，顶部有标题条，可按住拖动到任意位置。
  • 标题条上依次是「刷新」「透明度」「置顶」「主窗口」和关闭按钮：透明度滑块可在30%至100%之间调节；「置顶」按钮切换是否始终显示在其他窗口之上。
  • 窗口尺寸与位置、透明度、置顶状态都会被记住，下次启动自动恢复。
  • 快捷键：CommandOrControl+Shift+B显示或隐藏悬浮窗，CommandOrControl+Shift+W唤起主窗口。macOS首次使用全局快捷键时，如系统未授权，会在主窗口页脚提示，需在系统设置→隐私与安全性→辅助功能中允许本应用。
  • 悬浮窗与主窗口展示同一份数据，在任一窗口修改的设置会同步生效。

补充说明：

  • 密钥输入框始终以空白显示。若该平台已配置，占位文字会显示「已配置（尾号xxxx），留空表示不修改」，页面不会显示完整密钥。
  • 地址类设置必须是完整的http或https地址；自动刷新间隔只接受0（关闭）或30至86400秒之间的整数。不符合要求时保存会失败并给出弹出提示。

七、典型使用场景

首次配置并查看余额

  1. 按「启动与退出」一节启动软件，浏览器打开页面。
  2. 此时两张卡片显示「尚未配置API密钥」及对应建议。
  3. 点击「设置」，分别填入智谱GLM与DeepSeek的API密钥；按账户实际情况选择智谱余额币种和自动刷新间隔。
  4. 点击「保存并刷新」。页面收起设置面板并重新查询，卡片显示金额、币种与最近更新时间。

日常查看与手动刷新

  • 每次打开页面会自动查询一次。点击「刷新余额」可立即重新查询。
  • 查询进行中按钮显示「查询中…」并暂时禁用，避免重复发起请求。
  • 查询成功后，状态条显示「两个平台均查询成功」并附上本次时间；若有平台失败，状态条显示失败数量。

定时自动刷新

  • 在「自动刷新间隔」中选择一个间隔，状态条显示「自动刷新：每X分钟」以及「距下次刷新mm:ss」倒计时。
  • 每次查询完成后重新计时；从其他标签页或后台切回本页面时，若已到刷新时点会自动补刷一次。
  • 选择「关闭」后只保留手动刷新，倒计时区不再显示内容。

更换或清除密钥

  • 更换：在对应密钥输入框填入新值并保存，旧值即被覆盖。
  • 清除：点击对应分组的「清除」按钮，该平台的密钥立即被删除，卡片随即给出「尚未配置API密钥」提示。
  • 若密钥疑似泄露，建议先在平台控制台删除该密钥、创建新密钥，再回到设置中填写新值。

在手机或平板上查看

  1. 以HOST=0.0.0.0 python3 server.py启动服务（使用Node.js后端时改为HOST=0.0.0.0 node server.js）。
  2. 在同一局域网内的手机或平板浏览器中，打开终端或页面底部给出的局域网地址。
  3. 页面自动切换为单列布局，按钮铺满宽度，卡片中的时间与明细自动折行。

平台接口变更时

  • 智谱官方未提供公开的余额查询API，软件内置三个平台控制台所使用的账户接口并依次自动回退。若均不可用，可在「高级选项 → 自定义余额接口地址」填写能返回余额字段的完整地址，保存后继续查询。
  • DeepSeek侧可在「余额接口地址」中改填可用的兼容地址。
  • 接口恢复后，把自定义地址清空并保存，即可回到内置接口。

八、输入与输出说明

输入

软件只接收以下输入，不需要账号密码、账户ID，也不接收文件：

  • 设置面板中的两个API密钥、币种选择、接口地址、自定义余额接口地址、自动刷新间隔。
  • 页面上的操作：刷新余额、展开或收起设置、保存并刷新、取消、清除密钥。
  • API密钥支持直接粘贴：桌面应用主窗口按CommandOrControl+V，浏览器形态按系统粘贴快捷键；菜单栏「编辑」菜单也提供粘贴、复制、剪切与全选。

密钥由本地服务读取后用于向平台发起带鉴权头的只读请求，单次请求默认等待12秒。

输出

每张余额卡片包含以下内容：

币种徽标CNY或USD；尚未查询时显示「待查询」

其他输出：

  • 页面底部弹出提示显示设置保存、密钥清除、保存失败以及无法连接本地服务等操作结果。
  • 查询成功后，结果会保存在当前浏览器的本地存储中，下次打开页面可立即看到；查询失败且存在历史成功数据时，卡片仍显示上次的金额，同时给出本次失败的错误提示。清除浏览器站点数据会清空这部分缓存，但不会影响保存在本机的密钥。

十、注意事项与功能边界

  • 密钥只保存在本机的用户配置目录config.json，页面只接收脱敏后的尾号信息，不上传任何凭据。以HOST=0.0.0.0开放局域网访问时，同一网络内的其他设备可以打开页面并触发余额查询，请只在可信网络使用该方式。
  • 智谱官方未提供公开的余额查询API，软件使用平台控制台所使用的账户接口并做多端点回退；该接口可能随平台改版失效，届时可填写自定义余额接口地址，或直接到平台控制台查看。DeepSeek使用官方余额接口。
  • 智谱标准API密钥与Coding Plan套餐密钥分开管理，用错类型可能查到0或不匹配的金额；密钥也必须与接口站点匹配。
  • 金额按两位小数展示，精确值需查看金额悬停提示。余额明细随平台实际返回内容变化，平台未返回的字段不会显示。
  • 自动刷新会按设定间隔持续向平台发起只读请求。间隔过短可能触发平台限流，建议使用界面提供的最小间隔或更大的间隔。
  • 软件不提供账号密码登录、充值、账单明细与历史趋势、余额告警与通知、数据导出、多账户切换，也不修改平台账户设置。
  • Python版与Node.js版后端功能等价，共用同一份config.json与同一套页面；切换启动方式不会丢失已保存的配置。
  • 早期版本把配置保存在程序目录下的data/config.json；升级后程序改用系统用户配置目录，首次启动会把旧目录中的配置自动复制过去，旧文件保留不删除，确认无误后可自行清理。
  • 需要把配置放到自定义位置时，可在启动前设置环境变量BALANCE_DATA_DIR指定目录，程序改用该目录存放config.json；该变量对Python版与Node.js版同时生效。
  • 重复双击启动脚本不会启动第二个服务：脚本能识别出余额看板已在运行，此时只打开浏览器。
  • 关闭本地服务后页面将无法刷新；已保存的配置与浏览器中的历史余额快照仍会保留，下次启动后可继续使用。
  • 桌面应用与浏览器访问共用同一份配置与同一套界面，配置文件即位于桌面应用的系统用户数据目录中，窗口状态文件window-state.json与配置文件同目录并存、互不覆盖。
  • 悬浮窗透明度调节依赖系统窗口合成能力，Linux版本下不可用，此时滑块会被禁用。
  • 桌面应用的安装包未做代码签名与公证，首次打开需手动确认；仅在可信来源获取安装包时再执行。
